# Contribuer

Les issues et pull requests sont bienvenues.

Avant de proposer une modification :

1. partez d'une branche dédiée ;
2. gardez la logique de combat côté serveur Java ;
3. ne fournissez aucun fichier propriétaire Dofus, SWF, FLA, dump SQL ou configuration contenant des identifiants ;
4. compilez avec `build.bat` ;
5. testez les écritures sur une base locale de développement et conservez les sauvegardes générées.

Une pull request doit expliquer le comportement modifié, les tables concernées et la procédure de test utilisée.
